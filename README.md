 Program Description:
This project is a baby photoshop that allows users to apply different filters to images. The program supports 16 filters and 2 bonus filters.

  Available Filters
- **Filter 1:** Grayscale 
- **Filter 2:** Black and White
- **Filter 3:** Invert Image
- **Filter 4:** Adding a Frame to the Picture
- **Filter 5:** Flip Image
- **Filter 6:** Rotate Image
- **Filter 7:** Darken and Lighten Image
- **Filter 8:** Resizing Images
- **Filter 9:** Merge Images
- **Filter 10:** Detect Image Edges
- **Filter 11:** Crop Images
- **Filter 12:** Blur Images
- **Filter 13:** Sunlight
- **Filter 14:** TV effects
- **Filter 15:** Purple Tint
- **Filter 16:** Samurai Infrared Filter
- **Filter 17:** Image Skewing Filter
- **Filter 18:** Oil painting

-  Bonus & Extra filters are common between all members.
